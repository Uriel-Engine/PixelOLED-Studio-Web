# PixelOLED Studio Web

Version Web de PixelOLED Studio

## Compatibilidad

- Editor SSD1306 de 128×64 y 128×32.
- Herramientas de dibujo, formas, texto, selección, frames y exportación/importación de bitmaps C.
- USB/Serial mediante Web Serial API en Chrome o Edge, a 115200 baudios.
- Compatible con el firmware de PixelOLED Studio: paquetes `AA | comando | longitud LE | datos | XOR`, con confirmación y reintentos.
